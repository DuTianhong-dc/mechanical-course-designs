# 机械本科的课程设计

> 三个机械类课程设计的完整数字化存档 —— 设计计算、三维建模、图纸与设计文档

本仓库收录本科阶段完成的三份课程设计成果。每个项目自包含（模型、图纸、文档齐备），可独立浏览、打开与参考。

## 🚀 快速指路

- **各项目的详细内容、打开方式与免责说明** → 请先读各目录下的 `README.md`（重要）；
- 所有 SolidWorks 模型均附 **SW2024 兼容版**（`兼容版_SW2024/`），2024 / 2025 / 2026 均可直接打开；
- 模型全部**自包含**（零件 + 标准件同目录），无需配置 Toolbox，无需任何引用定位。

## ⚠️ 说明

- 三个项目均为**学习性质的课程作业**，不构成权威工程参考；具体免责与已知简化请见各目录 `README.md`；
- 含个人信息或他人协作内容的文件（任务书、部分工艺资料等）未收录于本仓库。
