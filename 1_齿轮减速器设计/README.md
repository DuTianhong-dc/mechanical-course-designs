# 1 · 齿轮减速器设计

> 机械设计课程设计 —— **二级展开式斜齿圆柱齿轮减速器**（含步进式工件输送机工作机机构）

本目录是课程设计的完整数字化存档：三维模型（SolidWorks）、图纸（AutoCAD）、演示文档。

---

## 📁 项目内容

### `模型/` —— SolidWorks 三维模型

| 内容 | 说明 |
|---|---|
| `减速器总装.SLDASM` | **完整总装体**（74 个组件），从这里开始看 |
| `减速器-*.SLDPRT` | 全部自制零件：三根轴（输入/中间/输出）、三组齿轮（高速级/低速级斜齿轮）、箱体（基座/箱盖）、端盖与套筒、附件（油标尺/油塞/通气器/定位销/盖板）等 |
| `曲柄连杆机构.SLDASM` + `底座 / 曲柄 / 连杆 / 摇杆 / 连架杆` | 工作机（步进式工件输送机）的曲柄摇杆机构 |
| `标准件/` | 从 SolidWorks Toolbox 实体化的标准件：深沟球轴承、六角法兰面螺栓/螺母、普通平键、弹簧垫圈、内六角圆柱头螺钉 —— **已实体化到本地，无需配置 Toolbox 即可打开** |

> **`兼容版/` —— 旧版本模型包（按 SW 版本分包）**
> 原版模型为 SolidWorks 2026 格式（2024 及更早版本打不开）。本目录提供两个 zip 分发包：
> - **`减速器总装2024.zip`** —— SolidWorks **2024 / 2025 / 2026** 均可直接打开
> - **`减速器总装2025.zip`** —— SolidWorks **2025 / 2026** 可直接打开
> - 下载对应 zip 解压后打开 `减速器总装.SLDASM`（自包含，无需引用定位）

### `图纸/` —— AutoCAD 图纸

| 文件 | 说明 |

| `工作机.dws` | 工作机装配图 |

### `文档/` —— 演示文档

| 文件 | 说明 |
|---|---|

## 🚀 打开方式

1. 使用 **SolidWorks 2026**（或更高版本）打开 `模型/减速器总装.SLDASM`；**旧版本（2024/2025）请下载 `模型/兼容版/` 下对应版本的 zip 包**；
2. 全部零件与标准件都在同一目录内，模型**自包含**——直接打开即可，无需做任何引用定位；
3. 图纸用 **AutoCAD 2018 及以上**打开。

## ⚠️ 重要提示

### 关于设计说明书

> **本项目的设计说明书为纯手写版，没有电子备份，已随作业上交存档。**

如果需要一份说明书，建议：
- 对照本仓库的**模型与图纸自行测量、逆向**，提取设计参数；
- 借助 **AI 工具**辅助整理，重建一份完整的设计说明书。

### 关于模型可维护性

> 由于早期建模过程存在不规范之处，**部分复杂零件的设计树几乎不具备可维护性**（修改早期特征极易引发连锁报错，修复成本远高于重做）。

**建议**：
- 需要调整时，请在**现有模型基础上"添加"或"局部修补"**（新增特征 / 切除 / 替换零件）；
- **不要**尝试修改早期设计树中的历史特征。
