# 3 · 卡罗拉（E210）前悬架设计

> 机械设计课程设计 —— **卡罗拉（E210）麦弗逊式前悬架设计**
> 全流程：调研 → 设计计算 → 参数化建模 → 交付文档

本目录是课程设计的完整数字化存档：调研报告、设计计算书（8 节）、参数表（14 张）、SolidWorks 模型、工作流脚本与设计说明书。

## 🚀 打开方式

1. **SolidWorks 2026**（或更高版本）打开 `03_模型/麦弗逊悬架.SLDASM`；使用 **2024 / 2025** 的软件请打开 `03_模型/兼容版_SW2024/` 内的同名装配体；
2. 模型**自包含**（全部零件 + 标准件在同一目录内），直接打开即可，无需任何引用定位。

## 🔧 参数化工作流说明

```
02_参数/NN_零件.toml     ← 完整参数体系 · 设计留档（基本尺寸 + 公式派生 + 校验注释）
03_模型/零件_参数.txt     ← 模型接口 · SolidWorks 外部方程式文件（与模型已链接）
        ↓  修改数值 → 在 SolidWorks 中刷新（重建）
03_模型/零件.SLDPRT      ← 尺寸联动更新
```

**修改参数的方法**：直接编辑 `03_模型/零件_参数.txt` 中的数值，再在 SolidWorks 中刷新（重建）模型即可——非常方便。

> ⚠️ **注意事项**
> - 含**曲面**（如【下摆臂】）或**样条曲线**（如【转向节】）的复杂零件，改参数常会引发报错（一般较易解决）——建议先查看该零件的**设计树**，了解建模过程，便于定位修复；
> - SolidWorks 保存模型时会**重写外部方程式文件**（使其与模型保持同步），属正常现象；带注释的完整参数推导请查阅 `02_参数/` 的 TOML 留档。

> 💡 本参数化结构为**首次尝试**、较为简单——如果你探究出更高效的参数管理方式，欢迎自行改进。

## 🔩 已知简化与取舍

| 项 | 说明 |
|---|---|
| **转向横拉杆** | 因余力不足未独立设计——**直接沿用下摆臂的对应结构、配套球头总成**（转向节上的安装位亦同）；**后续如需优化，建议从这里入手** |
| **减振器内部** | **阀体等内部零件未建**（仅壳筒身等外部结构），需要时请自行设计 |
| **螺旋弹簧** | 因 SolidWorks 柔性件功能不好用，弹簧**按压缩状态直接建成固定模型**装配（不含压缩变形能力）|
| **防尘** | 防尘方面已省略（未建防尘相关结构）|
