1 绪论

1.1 设计任务

依据课程设计任务书，完成卡罗拉汽车前悬架的设计，交付物包括：

  1. 前悬架装配图（1 张）
  2. 减振器壳零件图（1 张）
  3. 下摆臂零件图（1 张）
  4. 设计说明书（本文件）

1.2 车型确认

任务书给出的整车参数（85 kW / 185 N·m / 2700 mm 轴距 / 180 km/h / 1770 kg / 195/65 R15）与一汽丰田卡罗拉 1.2T（第 12 代，E210，TNGA-C 平台）配置完全对应，设计以 E210 为原型开展。

详细调研见 00_调研/卡罗拉前悬架调研报告.md。

1.3 悬架方案

卡罗拉前悬架为麦弗逊式（MacPherson）独立悬架——紧凑型轿车前悬最主流的形式。基本组成为螺旋弹簧 + 减振器支柱 + 下摆臂 + 横向稳定杆，配副车架、转向节。

麦弗逊的核心特征：减振器兼作滑动主销；侧向力大部分由下摆臂承受；弹簧缓冲、减振器衰减振动。优点是结构紧凑、非簧载质量小、成本低；缺点是抗侧倾能力弱（需稳定杆弥补）、滑柱受侧向力大——本设计通过偏频选择与几何布置（侧倾中心高度、主销倾角）予以控制。

1.4 设计方法

采用正向设计流程：

设计目标（偏频/挠度） → 载荷计算 → 刚度与杠杆比 → 导向机构几何
  → 零件设计（弹簧/减振器/壳体/摆臂） → 强度校核 → 建模出图

全部参数收录于参数文件（见附录 A）；承力零件的几何由参数文件驱动、在 SolidWorks 中按链接的方程式 txt 建立与重建。

2 设计目标与载荷计算

2.2 轴荷分配与轮荷

满载工况前轴荷分配按 60 %（FF 紧凑型轿车典型值）：

G₁ = m · g · 60% = 1770 × 9.8 × 0.60 = 10 407.6 N ≈ 10.41 kN
F_z = G₁ / 2 = 5203.8 N ≈ 5.20 kN   （单侧前轮，折合 531 kg）

2.3 簧载质量

单侧非簧载质量（车轮总成、转向节、轮毂、制动器、摆臂外侧段）取工程假设 m_u ≈ 60 kg：

m_s = 531 − 60 = 471 kg    （单侧簧载质量）

2.4 平顺性目标：偏频与静挠度

设计目标偏频（前悬架、满载）取 n = 1.25 Hz（轿车前悬常规 1.2～1.4 Hz，舒适取向）。静挠度（教材近似式 n = 5/√f_c）：

f_c = 25 / n² = 16.0 cm = 160 mm

校核：精确式 n = (1/2π)·√(g/f_c) 反算 f_c ≈ 159 mm，一致 ✓

2.5 悬架刚度（轮心等效）

C = m_s·g / f_c = 471 × 9.8 / 0.160 = 28 849 N/m ≈ 28.8 N/mm

3 悬架刚度与杠杆比

源自 01_设计计算/02_杠杆比与弹簧刚度.md

3.1 杠杆比的定义

麦弗逊悬架的螺旋弹簧经"减振器支柱 + 下摆臂"机构传力，弹簧变形与轮心位移之间存在杠杆比（运动比）i：

i = 弹簧轴向变形量 / 轮心垂直位移量        （i < 1，典型 0.85～0.97）

由能量法，轮心刚度与弹簧刚度关系：

C = k · i²      即    k = C / i²

弹簧静载力（虚功原理）：F_spring = F_w / i

3.2 杠杆比取值

近似式 i ≈ a/b（a 为弹簧盘中心线至摆动轴线的垂直距离，b 为轮心至摆动轴线的垂直距离）。

本阶段取 i = 0.93（麦弗逊常规 0.85～0.97 的中上值）。

⚠️ 设计初期假定值——第 4 章硬点布置完成后复核：弹簧盘位置距底端 148～154 mm，a/b 复核与 0.93 假定基本一致（详见 4.3 节与第 5 章弹簧装配链）。 → 该假定后被第 7 章的缓冲块介入点判据修正为 191 mm（见 7.2 节）。

3.3 螺旋弹簧刚度

k = C / i² = 28 849 / 0.93² = 33 355 N/m ≈ 33.4 N/mm

3.4 弹簧静载力与静压缩量

F_s = m_s·g / i = 4615.8 / 0.93 = 4963 N ≈ 4.96 kN
δ_s = F_s / k = 4963 / 33.4 = 148.6 mm

交叉校核：δ_s = f_c × i = 160 × 0.93 = 148.8 mm ✓ 自洽。

3.5 本章结论

量 数值
杠杆比 i 0.93
螺旋弹簧刚度 k 33.4 N/mm
弹簧满载静载力 F_s 4.96 kN
弹簧静压缩量 δ_s 148.8 mm

4 导向机构几何设计

源自 01_设计计算/05_导向机构几何设计.md

4.1 坐标系与布置基准

横断面坐标系（车辆前视）：原点为车辆中线与地面交点，Y 横向向外，Z 高度向上。基准：半轮距 B/2 = 763.5 mm，车轮滚动半径 317 mm。

4.2 关键硬点坐标

硬点 符号 X (mm) Y (mm) Z (mm) 说明
下摆臂内铰点（摆动轴线中心） A +24.9 369.3 204 副车架上
下摆臂外端（下球头中心） B +24.9 689.3 207 轮辋内侧、轮心下方（主销轴线上）
支柱下端（转向节夹持中心） S +24.2 686.4 220 与球头邻近（主销轴线上）
支柱上支点（顶胶中心） P −16.3 523.5 950 车身上（主销轴线上）
轮心（基准） W 0 763.5 317
轮胎接地点 G 0 763.5 0 轮心正下方

X 轴基准：取轮心 X = 0，主销轴线在 XZ 投影内距轮心 18.8 mm（垂直距，轴线位于轮心前方；与 70_转向节.toml 模型值一致）。 轴线方程 X(Z) = +18.8 − 0.055383×(Z − 317)。

下摆臂长度（水平投影）：L_A = 689.3 − 369.3 = 320 mm。内端低（204）、外端高（207），上翘 0.54°。

4.3 主销轴线与倾角校核

主销轴线 = 支柱上支点 P 与下端 S 的连线，与丰田官方定位参数一致：

主销轴线方程（横向）：Y = 735.5 − 0.2232·Z   （地面交点 Y = 763.5 − 28 = 735.5）
主销内倾角 α = atan[(686.4−523.5) / (950−220)] = 12.58°   （官方 12°35′ ✓）
主销后倾角 β = 3.17°                                       （官方 3°10′ ✓）
主销与铅垂线的真夹角（三维）= 12.95°                       ← 装配实际角度
主销偏移距 = 763.5 − 735.5 = 28 mm                         （官方反推 25~30 ✓）
主销后倾拖距 = +36.4 mm                                    （正当值，自动回正）
轮心至轴线距离 = 98.4 mm（转向节悬臂长度）
                     ├ 在【主销轴线+铅垂线】竖直平面内 = 89.1 mm
                     └ 垂直于该平面                     = 41.7 mm

★ 以【轴承座中间面】为基点（= 轮心内侧 22 mm，即 Y = 741.5）：
     至轴线距离 = 77.4 mm（面内 68.2 ｜ 面外 36.4）
     轴承座中间面到轮心的距离 D = 30 + 32 − 40 = 22 mm
       ① 轮心→轮辋安装面 ET = 40（6.5J×15 ET40，原厂轮辋）
       ② 轮辋安装面→转向节孔外端面 = 30（估）
       ③ 孔外端面→孔中间面 = 64/2 = 32（轴承座孔深 64）

三个角的区分：主销内倾 12.58° 在前视（YZ）量、主销后倾 3.17° 在侧视（XZ）量， 而实际装配中主销轴线与铅垂线的真夹角为 12.95°（= 两倾角的三维叠加， 恒大于任一投影角）。

4.4 侧倾中心高度

瞬心 IC 作图：下摆臂线 AB（斜率 0.009375）与过 P 垂直于支柱轴线的直线（斜率 +0.2232）交于 IC = (−2959, 173)；接地点 G 与 IC 连线（斜率 −0.046414）交车辆中线：

h_rc = 0.046414 × 763.5 ≈ 35.4 mm   （常规 0~100 mm ✓，偏低设定）

4.5 运动校核

摆臂总摆角（压缩 70 + 复原 90 mm）：θ = asin(160/320) ≈ 30.0°；轮距变化全行程约 15～20 mm，属紧凑型轿车常规水平。

5 螺旋弹簧设计

源自 01_设计计算/03_螺旋弹簧设计.md

📎 本章零件参数文件（单一参数源，点击跳转）： 02_参数/10_螺旋弹簧.toml

5.1 设计输入

参数 数值 来源

满载静载力 F_s 4.96 kN 第 3 章
静压缩量 δ_s ≈ 149 mm 第 3 章

5.2 材料与许用应力

材料选 60Si2MnA（弹簧钢，GB/T 1222），弹性模量 G = 79 000 MPa，抗拉强度 ≥1650 MPa。

许用切应力 [τ] = 0.46σ_b = 760 MPa
极限切应力 [τ]_max = 0.65σ_b = 1070 MPa

5.3 簧丝直径

按许用切应力与曲度系数迭代：

d ≥ 1.6·√(F_max·K·c / [τ])
初取 c = D/d ≈ 8.7，K = 1.156
→ d = 13.5 mm（弹簧钢丝标准系列）

5.4 中径与圈数

D = c·d = 8.7 × 13.5 ≈ 118 mm
弹簧刚度要求 k = Gd⁴/(8D³n) → n = 6 圈（有效圈）
总圈数 n₁ = n + 2 = 8（两端各并紧 1 圈，磨平）

5.5 自由高度与节距

自由高 H₀ = 静压缩量 + 剩余高度 + 并紧段 … = 330 mm
有效段节距 p = (H₀ − 1.5d)/n = 51.625 mm

5.6 端部结构与磨平

两端并紧磨平（GB/T 1239.1 YI 型）：

  • 磨平部分 ≥ 3/4 圈（磨面角 270°）
  • 端头厚度 ≈ 0.25d = 3.375 mm
  • 支承圈与有效圈并紧

5.7 强度校核

静载：τ = 8F_s·D·K/(πd³) = 701 MPa ≤ 760 MPa ✓（n=1.90）
极限：τ_max = 919 MPa ≤ 1070 MPa ✓（n=2.30）

5.8 本章结论

簧丝直径 φ13.5
中径 φ118
自由高度 330 mm
有效圈 / 总圈 6 / 8
节距（有效段） 51.625 mm
材料 / 旋向 60Si2MnA / 右旋
静载 / 极限切应力 701 / 919 MPa（均合格）
单件质量 ≈ 3.36 kg

⚠️ 上口 φ38 的几何疑点：此值小于筒体内腔 φ42，而"车削"只能扩大孔径、做不出更小的孔， 故"在内腔 φ42 里车出一个 φ38 的上口孔"物理上不成立。两种可能：(a) 上端段是加厚壁 （壁厚 4 而非 2），内孔 38 成立；(b) 38 实为导向器/油封总成的外径，筒体上口仍是 φ42、只需倒角。 二者建模结果不同（详见参数文件对应注释）。

⚠️ 下支架轴向位置：计算书未给定，待装配图 / 转向节接口确定后补，不影响轮廓建模。

8 下摆臂结构设计

源自 01_设计计算/06_下摆臂结构设计.md

📎 本章零件参数文件（单一参数源，点击跳转）： 02_参数/20_下摆臂.toml

8.1 结构形式

钢板冲压焊接式下摆臂（A 形双臂结构）：内侧两个铰接点（前后向布置，橡胶衬套，与副车架连接）、外侧球头座（装下球头，接转向节）。臂体由两片冲压钢板各自冲成 U 形后对扣成箱形截面——左右侧壁相互重叠（每侧 2 层板），顶壁 / 底壁各 1 层；周边及侧壁重叠处焊接。

截面沿长度分三段，各自独立（不是等截面）：

段 位置 截面 外宽 B × 外高 H B/H 设计逻辑
外端球头安装段 P1 附近 50 × 60 mm 0.83 弯矩最大 → 优先抗弯，高而窄
中间主体段 中段 42 × 45 mm 0.93 抗弯抗扭均衡、减重优先
内端衬套安装段 P2 / P3 附近 55 × 50 mm 1.10 侧向力集中 → 加宽提升抗扭与衬套空间

板厚统一 t = 3 mm。两片 U 形对扣后：内宽 = 外宽 − 4t，内高 = 外高 − 2t（左右侧壁各 2 层 → 扣 4 层；顶底各 1 层 → 扣 2 层）。

8.2 计算载荷

最恶劣工况为侧向（转弯），轮胎侧向力经转向节传至球头：

F = μ · F_z · k_d · λ = 0.8 × 5204 × 1.4 × 0.6 = 3497 N ≈ 3.5 kN

力学模型为悬臂梁（球头端受侧向力，内端铰接固定）。力臂取有效摆长 320 mm——即球铰点 P1 到摆动轴线的垂直距离，也就是侧向力对该轴线的力臂：

M_max = F · L_eff = 3500 × 0.320 = 1120 N·m

8.3 截面设计与弯曲校核

最薄弱截面取中间主体段（三段中截面最小，而弯矩仍大）：外宽 42 × 外高 45，板厚 3：

内腔 b × h = (42 − 4×3) × (45 − 2×3) = 30 × 39 mm
W = (42×45³ − 30×39³) / (6×45) = 7584 mm³
σ = M_max / W = 1 120 000 / 7584 = 147.7 MPa

材料 QStE420（EN 10149-2 / SEW 092 的 S420MC，热机械轧制细晶高强钢；板厚 ≤ 3 mm 时屈服强度 ≥ 420 MPa）：

安全系数 n = 420 / 147.7 = 2.84 ✓

侧壁双层使更多材料远离中性轴，抗弯能力优于同等重量的单层壁截面。

8.4 连接结构设计

本件两端各有一种连接：内端与副车架铰接（2 处）、外端与转向节球铰（1 处）。两处的孔都采用焊接衬管工艺——避免箱形内腔中段空心带来的压装鼓胀与松动问题。

8.4.1 内端铰接：衬套总成（5 层）＋ 焊接衬管

层 零件 尺寸 (mm) 作用 / 配合
① 贯穿螺栓 M14×1.5，10.9 级 与副车架紧固，配自锁螺母
② 内金属套 φ14.5 × φ20 与螺栓留 0.5 微间隙
③ 橡胶层 厚 4（φ20 → φ28） 承担扭转变形与减振
④ 外金属套 φ28 × φ32 与摆臂孔过盈
⑤ 摆臂孔（衬管内孔） φ32 过盈配合面
— 衬管（焊接在臂板上） 内孔 φ32；外径 = 内端段截面高；长 65 圆管车制，穿过两片后两端焊死

②③④ 三层组成【衬套总成】，单独出图。为何不直接在两片上冲孔：箱形内腔中段是空的，衬套只有两端有径向约束 → 压装时外金属套会鼓胀、工作时无约束易松动异响；衬管提供连续、规整、壁厚可控的孔壁（壁厚 4），压装可靠。

8.4.2 外端球铰：整体式单壳球铰（压装 ＋ 端口滚铆）

外端采用乘用车主流的整体式单壳球铰：由 ① 球销、② 上下球座、③ 壳体、④ 防尘罩 组成。与内端"焊接衬管"不同，外端壳体靠压装过盈装入摆臂的球头座，端口滚铆翻边扣住上球座法兰实现轴向限位——不用螺栓，更紧凑也便于更换。

件 零件 尺寸 (mm) 材料
① 球销（另立件） 球面 φ25；锥面 1:11（大端 φ20 → 小端 φ15、长 55）；杆部 φ15；螺纹 M14×1.5 40Cr合金结构钢（调质＋高频淬火）
② 上下球座 下座 φ38 / 上座 φ38（带法兰 φ40×2），上座高 12；内球面 R12.5 25%玻纤增强聚甲醛（POM-GF25）＋内球面 PTFE 自润滑层
③ 壳体（整体式单壳） 等径 φ45；内孔主 φ38 / 端口 φ41；总高 50；压装段长 32 10号优质碳素结构钢（冷挤压）
④ 防尘罩（配套件） 下卡径 φ44 / 上卡径 φ16 / 自由高 28 EPDM，邵氏 60±5 A

与摆臂的连接：壳体压装段 φ45 压入摆臂「球头座内孔 φ45H7」（过盈 0.035~0.12、压装力 18~25 kN），压装后抗拔脱力 ≥ 18 kN；端口经高速旋压滚铆向内翻边 2.5~3 扣住上球座法兰，成品轴向窜动量 ≤ 0.15。

（注：端口需外扩到 φ41 才能让上球座法兰 φ40 通过——原按 φ42 外径／壁厚 2 得到的内孔只有 φ38，装不进。）

与转向节的连接：球销锥面 1:11 插入转向节锥孔，从上方用 M14×1.5 螺母拉合（锥面自定心、拉紧后无间隙；锁紧件为开槽螺母 GB/T 9457 + 开口销 φ3.2×26，力矩 90 N·m）；球头设 EPDM 防尘罩并注入极压锂基脂 ≈8 g。球销额定静载荷 ≥ 4 倍单侧轮荷（4 × 5204 = 20.8 kN ≈ 21 kN）。

9.2 关键校核过程

筒壁内压（薄壁环向应力）：

σ = p·D_in/(2t) = 2.5 × 42/(2×2) = 26.3 MPa ≪ 345 MPa ✓

A = 2 × 2.8 × π×46 ≈ 809 mm²；τ = 6504/809 = 8.0 MPa ≪ [τ] ✓
