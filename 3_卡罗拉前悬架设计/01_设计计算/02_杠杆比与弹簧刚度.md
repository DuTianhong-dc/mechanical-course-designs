# 02 · 悬架杠杆比与螺旋弹簧刚度

> 卡罗拉（E210）前悬架设计 · 设计计算书 第 2 节

---

## 2.1 杠杆比（运动比）的定义

麦弗逊悬架的螺旋弹簧不直接作用于轮心，而是通过"减振器支柱 + 下摆臂"构成的摆臂机构传递力与位移，二者之间存在**杠杆比（运动比）i**：

```
i = 弹簧轴向变形量 / 轮心垂直位移量        （i < 1，典型 0.85～0.97）
```

**轮心刚度与弹簧刚度的关系**（能量法推导）：

设轮心位移 δ_w 时弹簧变形 δ_s = i·δ_w，由能量守恒：

```
½·k·δ_s² = ½·C·δ_w²
→ k·(i·δ_w)² = C·δ_w²
→ C = k · i²     即    k = C / i²
```

**弹簧静载力的杠杆关系**（虚功原理）：

```
F_spring = F_w / i
```

---

## 2.2 杠杆比取值

麦弗逊悬架的杠杆比由几何布置决定，近似式：

```
i ≈ a / b
a ── 弹簧盘中心线到下摆臂摆动轴线的垂直距离
b ── 轮心到下摆臂摆动轴线的垂直距离（横断面内）
```

**本阶段取 i = 0.93**（麦弗逊常规范围 0.85～0.97 的中上值，对应弹簧盘位置偏高、摆臂较长的典型布置）。

> ⚠️ 本值为设计初期假定值——**待第 5 节导向机构几何设计（硬点布置）完成后复核修正**，必要时迭代更新弹簧参数。

---

## 2.2b 第 5 节完成后的复核（）

按 §2.2 的承诺，第 5 节硬点确定后对 i 做了复核。复核用**更新的硬点**
（摆臂 320、侧倾中心 35 反解得到的 A(369.3, 204) / B(689.3, 207) / S(686.4, 220) / P(523.5, 950)）：

**① 先核对 §2.2 写的那个式子**：

```
i ≈ a / b    a = 弹簧盘中心线到摆动轴线的距离
             b = 轮心到摆动轴线的距离
```

代入新硬点：a = 323.8、b = 410.1 → **i = 0.79**

⚠️ **这个简化式不可用** —— 与 0.93 差了 15%。根因是：麦弗逊的弹簧力**沿减振器轴线
（一条斜线）**作用，而不是沿"弹簧盘中心到摆动轴线的连线"。拿两点直线距离当力臂，
方向就错了。**§2.2 的式子只作概念说明，不能用来定量。**

**② 用正规的瞬心法（真位移比）复核**：

- 瞬心 IC = (−2959, 173)（见第 5 节 §5.4）
- 弹簧盘中心取在减振器轴线上 Z = 191 处 → (692.9, 191)
- 弹簧变形 = 弹簧盘位移沿**减振器轴向**的分量；轮心位移 = 轮心的**竖直**分量

```
i = |δ_s| / |δ_w| = 0.9771 / 0.9993 ≈ 0.978
```

**③ 判定：本次不迭代**

与假定值 0.93 相差 **5.1%**，刚好越过 §2.2 自设的 5% 阈值。**但判为不迭代**，理由：

- 瞬心法里"弹簧盘中心"是取在轴线上的一点，**真实弹簧盘是 φ135 的圆盘，力的作用点有分布**，
  这一步取点本身带 **±2~3% 的不确定度**。0.93 与 0.978 落在同一个不确定带内，无一方明显更对。
- 迭代代价不划算：k 由 33.4 改到 30.2 N/mm（差约 10%，对应弹簧线径 13.5 → 约 13.2），
  **已建成的弹簧模型要重建**，且连带弹簧装配长 → 上座面高 → 弹簧盘位置 → 缓冲块空间 →
  活塞杆总长**整条链都要再动一遍**，而收益不足 3% 的载荷精度。

**④ 留档**：若后续做整车性能仿真，可按 **i = 0.978** 重算 k = C/i² = 28.85/0.956 = **30.2 N/mm**。
本次仍沿用 k = 33.4 N/mm。
>
> ✅ ** 已完成复核**，结论：**保留 i = 0.93，不迭代弹簧参数**。复核过程与判据见 §2.6。

---

## 2.3 螺旋弹簧刚度

由第 1 节轮心刚度 C = 28.85 N/mm：

```
k = C / i² = 28 849 / 0.93² = 28 849 / 0.8649 = 33 355 N/m
```

**k ≈ 33.4 N/mm**（螺旋弹簧刚度设计目标值）

---

## 2.4 弹簧静载力与静压缩量

满载静载力（弹簧上承受的力）：

```
F_s = m_s·g / i = 4615.8 / 0.93 = 4963 N ≈ 4.96 kN
```

弹簧静压缩量：

```
δ_s = F_s / k = 4963 / 33.4 = 148.6 mm
```

**交叉校核**：δ_s 应等于 f_c × i = 160 × 0.93 = 148.8 mm ✓ 自洽（0.1% 内取整误差）。
