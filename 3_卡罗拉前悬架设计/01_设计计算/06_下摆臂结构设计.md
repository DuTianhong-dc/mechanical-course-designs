# 06 · 下摆臂结构设计

> 卡罗拉（E210）前悬架设计 · 设计计算书 第 6 节

---

## 6.1 结构形式

**型式**：钢板冲压焊接式下摆臂（A 形双臂结构）。

- 内侧两个铰接点（前后向布置，与副车架连接，橡胶衬套）
- 外侧球头座（安装下球头，与转向节连接）
- 臂体由两片冲压钢板**各自冲成 U 形后对扣**成箱形截面：左右侧壁相互重叠（**每侧 2 层板**），
  顶壁 / 底壁各 1 层；周边及侧壁重叠处焊接

> 选型依据：A 形双臂 + 冲压焊接是紧凑型轿车下摆臂的主流形式；工艺为冲压 + 焊接，适合大批量生产；通过盒形截面在轻量化条件下获得足够抗弯/抗扭刚度。

---

## 6.2 计算载荷

**最恶劣工况**：侧向（转弯）工况，轮胎侧向力经转向节传递至球头。

```
F = μ · F_z · k_d · λ
  μ  — 附着系数，取 0.8
  F_z — 满载单侧轮荷 5204 N
  k_d — 动载系数，取 1.4
  λ  — 摆臂分担系数，取 0.6（其余由减振器支柱承受）
```

```
F = 0.8 × 5204 × 1.4 × 0.6 = 3497 N ≈ 3.5 kN
```

**力学模型**：悬臂梁（球头端受侧向力 F，内端铰接固定）。**力臂取【有效摆长】320 mm**
—— 球铰点 P1 到摆动轴线的垂直距离，也就是侧向力对该轴线的力臂
（值与 `02_参数/20_下摆臂.toml` 的「有效摆长」一致）：

```
M_max = F · L_eff = 3500 × 0.320 = 1120 N·m
```

## 6.3 截面设计与弯曲校核

**截面沿长度分三段，各自独立——不是等截面**（两片 3 mm 冲压板各自冲成 U 形后对扣）：

| 段 | 位置 | 外宽 B × 外高 H | B/H | 设计逻辑 |
|---|---|---|---|---|
| 外端球头安装段 | P1 附近 | 50 × 60 mm | 0.83 | 弯矩最大 → 优先抗弯，高而窄 |
| **中间主体段** | 中段 | **42 × 45 mm** | 0.93 | 抗弯抗扭均衡、减重优先 |
| 内端衬套安装段 | P2 / P3 附近 | 55 × 50 mm | 1.10 | 侧向力集中 → 加宽提升抗扭与衬套空间 |

板厚统一 t = 3 mm。两片 U 形对扣后 **内宽 = 外宽 − 4t、内高 = 外高 − 2t**
（左右侧壁各 2 层 → 扣 4 层；顶底各 1 层 → 扣 2 层）。

**最薄弱截面取中间主体段**（三段中截面最小，而弯矩仍大）：

| 截面参数 | 数值 |
|---|---|
| 外宽 B × 外高 H | 42 × 45 mm |
| 内腔 b × h | **30 × 39 mm** |
| 抗弯截面系数 W | (42×45³ − 30×39³)/(6×45) = **7584 mm³** |

> 侧壁双层使更多材料远离中性轴，抗弯能力优于同等重量的单层壁截面。

**弯曲应力**：

```
σ = M_max / W = 1 120 000 / 7584 = 147.7 MPa
```

**材料**：**QStE420热机械轧制高强钢**（QStE420TM = EN 10149-2 S420MC，板厚 3 mm 时屈服强度 ≥ 420 MPa）

```
安全系数 n = 420 / 147.7 = 2.84 ✓
```

## 6.4 连接结构设计

本件两端各有一种连接：**内端与副车架铰接（2 处）**、**外端与转向节球铰（1 处）**。
内端的孔采用**焊接衬管**工艺——避免箱形内腔中段空心带来的压装鼓胀与松动问题；
外端则用**整体式单壳球铰**压入焊接的球头座（见 6.4.2）。

### 6.4.1 内端铰接：衬套总成（5 层）＋ 焊接衬管

层次结构（由内向外）：

| 层 | 零件 | 尺寸 (mm) | 作用 / 配合 |
|---|---|---|---|
| ① | 贯穿螺栓 | **M14×1.5**，10.9 级 | 与副车架紧固，配自锁螺母 |
| ② | 内金属套 | φ14.5 × φ20（壁 2.75） | 与螺栓留 **0.5 微间隙** |
| ③ | **橡胶层** | 厚 **4**（φ20 → φ28） | **承担扭转变形与减振** |
| ④ | 外金属套 | φ28 × φ32（壁 2） | 与摆臂孔**过盈** |
| ⑤ | 摆臂孔（衬管内孔） | φ32 | 过盈配合面 |

**②③④ 三层组成【衬套总成】，单独出图**（独立交付零件）。

**工艺方案：焊接衬管**

- 两片钢板端部冲孔（**φ50，与衬管外径配作**）；
- **衬管**（内孔 φ32 / 外径 **50**（= 内端段截面高）/ 长 **65**）由圆管车制，穿过两片后**两端焊死**。

**为何不直接在两片上冲孔**：箱形内腔中段是空的，衬套只有两端有径向约束 →
压装时外金属套会鼓胀、工作时无约束易松动异响。衬管提供**连续、规整、壁厚可控**的
孔壁（壁厚 4），压装可靠。

### 6.4.2 外端球铰：整体式单壳球铰（压装 ＋ 端口滚铆）

外端采用乘用车主流的**整体式单壳球铰**：由 **① 球销**、**② 上下球座**、**③ 壳体**、
**④ 防尘罩** 组成。与内端"焊接衬管"不同，外端壳体靠**压装过盈**装入摆臂的球头座，
端口**滚铆翻边**扣住上球座法兰实现轴向限位——不用螺栓，结构更紧凑、更便于更换。

| 件 | 零件 | 尺寸 (mm) | 材料 |
|---|---|---|---|
| ① | **球销**（另立件，见 `60_球头.toml`） | 球面 **φ25**；锥面 **1:11**（大端 φ20 → 小端 φ15、长 55）；杆部 **φ15**；螺纹 M14×1.5 | 40Cr合金结构钢（调质＋高频淬火） |
| ② | **上下球座** | 下座 φ38 / 上座 φ38（带法兰 φ40×2），上座高 12；内球面 R12.5 | 25%玻纤增强聚甲醛（POM-GF25）＋内球面 PTFE 自润滑层 |
| ③ | **壳体**（整体式单壳） | 等径 **φ45**；内孔主 φ38 / 端口 φ41；总高 **50**；压装段长 **32** | 10号优质碳素结构钢（冷挤压） |
| ④ | 防尘罩（配套件） | 下卡径 φ44 / 上卡径 φ16 / 自由高 28 | EPDM，邵氏 60±5 A |

**与摆臂的连接**：壳体压装段 φ45 压入摆臂「球头座内孔 φ45H7」（过盈 0.035~0.12，
压装力 18~25 kN、压入速度 10~20 mm/s），压装后**抗拔脱力 ≥ 18 kN**；
端口经**高速旋压滚铆**向内翻边 2.5~3，扣住上球座法兰，成品**轴向窜动量 ≤ 0.15**。

> 端口需外扩到 φ41 才能让上球座法兰（φ40）通过——原按 φ42 外径／壁厚 2 得到的内孔只有 φ38，装不进。

**与转向节的连接**：球销锥面 **1:11** 插入转向节锥孔，从上方用 M14×1.5 螺母拉合
（锥面自定心、拉紧后无间隙）；球头设 EPDM 防尘罩并注入球节专用极压锂基脂 ≈8 g。
锁紧件：**开槽螺母 GB/T 9457 M14×1.5 + 开口销 φ3.2×26**（力矩 90 N·m）。

**球头承载要求**：球销**额定静载荷 ≥ 4 倍单侧轮荷（4 × 5204 = 20.8 kN ≈ 21 kN）**
（极限侧向力经转向节传至球头），壳体壁厚与球径按此选取；具体校核见第 8 节强度汇总。

> **说明**：本设计采用**自研整体式单壳球铰**（交付零件之一），尺寸按成品下球头的常规比例取定
> ——球径 ≈ 2 × 螺纹直径、球座壁厚 3~4 mm、壳体筒壁厚 ≥ 球径的 1/8。

## 6.5 本节结论

| 项目 | 数值 |
|---|---|
| 结构型式 | 冲压焊接 A 形双臂（箱形截面） |

| 内端铰点间距 | **269 mm** |
| 材料 | 摆臂本体 QStE420热机械轧制高强钢 ｜ 衬管与内外套 20号优质碳素结构钢 ｜ 球销 40Cr合金结构钢 ｜ 球座 25%玻纤增强聚甲醛（POM-GF25） |
| 弯曲应力 / 安全系数 | **147.7 MPa / 2.84 ✓** |
| 内端连接 | 衬套总成（5 层）+ 焊接衬管（内孔 φ32 / 外径 50 / 长 65） |
