## 8.2 关键校核公式与过程

### 8.2.1 筒壁内压（薄壁环向应力）

```
σ = p·D_in / (2t) = 2.5 × 42 / (2×2) = 26.3 MPa ≪ 345 MPa ✓
```

> 结论：筒壁厚度由工艺（焊接变形、刚度）与既有管材标准决定，强度富余极大。

### 8.2.2 活塞杆稳定性（欧拉公式）

```
I  = πd⁴/64 = π × 15⁴/64 = 2485 mm⁴
P_cr = π²EI / L² = π² × 206 000 × 2485 / 300² = 56.1 kN
n = P_cr / F_max = 56.1 / 6.5 = 8.6 ✓
```

### 8.2.3 下摆臂（见第 6 节）

```
最薄弱截面：中间主体段 外宽 42 × 外高 45、板厚 3
W = (42×45³ − 30×39³) / (6×45) = 7584 mm³
M = 1120 N·m → σ = 147.7 MPa ≤ 420 MPa，n = 2.84 ✓
```

### 8.2.4 弹簧盘焊缝（角焊缝剪切）

```
焊脚 4 mm（双面），有效厚度 0.7×4 = 2.8 mm
焊缝面积 A = 2 × 2.8 × π×46 ≈ 809 mm²
τ = F_max / A = 6504 / 809 = 8.0 MPa ≪ [τ]_weld ✓
```

**全部校核项目通过。** 各零部件均为常规成熟结构，应力水平与安全系数处于同类产品的正常范围；最大应力部位出现在下摆臂臂体（147.7 MPa），安全系数 2.84，与冲压焊接摆臂（依赖高强度钢板 + 工艺强化）的典型设计水位一致。
