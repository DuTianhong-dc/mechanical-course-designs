# 01 · 载荷与设计目标

> 卡罗拉（E210）前悬架设计 · 设计计算书 第 1 节

---

## 1.1 设计输入（原始参数）

| 参数 | 符号 | 数值 | 来源 |
|---|---|---|---|
| 满载总质量 | m | 1770 kg | 课程设计任务书 |
| 轴距 | L | 2700 mm | 课程设计任务书 |
| 前轮距 | B₁ | 1527 mm | 公开车型数据（E210） |
| 最高车速 | v_max | 180 km/h | 课程设计任务书 |
| 驱动形式 | — | 前置前驱（FF） | 车型资料 |

---

## 1.2 轴荷分配与轮荷

**假设**：满载工况前轴荷分配 **60 %**（FF 紧凑型轿车典型值；待实测/老师给定数据修正）。

前轴垂直载荷：

```
G₁ = m · g · 60 % = 1770 × 9.8 × 0.60 = 10 407.6 N ≈ 10.41 kN
```

单侧前轮载荷：

```
F_z = G₁ / 2 = 5203.8 N ≈ 5.20 kN   （折合 531 kg）
```

---

## 1.3 簧载质量

单侧非簧载质量（车轮总成、转向节、轮毂、制动器、摆臂外侧段）**工程假设**：

```
m_u ≈ 60 kg
```

单侧簧载质量（偏频与刚度计算所用质量）：

```
m_s = 531 − 60 = 471 kg
```

---

## 1.4 平顺性目标：偏频与静挠度

**设计目标偏频**（前悬架、满载）：**n = 1.25 Hz**
（轿车前悬架常规范围 1.2～1.4 Hz，取舒适取向；避免与后悬架偏频接近）

静挠度（教材近似式 `n = 5/√f_c`，f_c 单位为 cm）：

```
f_c = 25 / n² = 25 / 1.25² = 16.0 cm = 160 mm
```

> 校核：由 n = (1/2π)·√(g/f_c) 精确式反算 f_c = 9800/(2π×1.25)² ≈ 159 mm，与近似式一致 ✓

---

## 1.5 悬架刚度（轮心等效值）

```
C = m_s · g / f_c = 471 × 9.8 / 0.160 = 28 849 N/m ≈ 28.8 N/mm
```

该刚度为**轮心处等效刚度**，后续经杠杆比换算得螺旋弹簧实际刚度（第 2 节）。

---

## 1.6 本节结论

| 量 | 数值 |
|---|---|
| 满载单侧前轮载荷 F_z | **5.20 kN** |
| 单侧簧载质量 m_s | **471 kg** |
| 目标偏频 n | **1.25 Hz** |
| 静挠度 f_c | **160 mm** |
| 轮心处悬架刚度 C | **28.8 N/mm** |

**衔接**：第 2 节由 C 经杠杆比 → 弹簧刚度；第 4 节减振器阻尼设计以 n 为频率基础。

**待核验假设**：① 前轴荷 60 %；② 非簧载 60 kg。后续若获得实测数据可直接更新数值，不影响流程完整性。
