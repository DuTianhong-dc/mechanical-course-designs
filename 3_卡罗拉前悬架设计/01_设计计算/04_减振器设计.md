# 04 · 减振器设计

> 卡罗拉（E210）前悬架设计 · 设计计算书 第 4 节

---

## 4.1 设计输入（第 1、2 节）

| 参数 | 数值 |
|---|---|
| 单侧簧载质量 m_s | 471 kg |
| 轮心悬架刚度 C | 28.85 N/mm |
| 固有频率（偏频） n | 1.25 Hz → ω₀ = 2πn = 7.85 rad/s |
| 杠杆比 i | 0.93 |

---

## 4.2 阻尼比与阻尼系数

**相对阻尼系数选取**（轿车常规）：

| 行程 | 符号 | 取值 |
|---|---|---|
| 复原（伸张）行程 | ψ_y | **0.40** |
| 压缩行程 | ψ_s | **0.20**（≈ ψ_y 的 0.5 倍） |
| 平均 | ψ̄ | 0.30 |

**临界阻尼基准**（轮心处）：

```
√(C·m_s) = √(28 849 × 471) = 3686 N·s/m
```

**轮心处阻尼系数**：

```
c_wy = 2·ψ_y·√(C·m_s) = 2 × 0.40 × 3686 = 2949 N·s/m （复原）
c_ws = 2·ψ_s·√(C·m_s) = 2 × 0.20 × 3686 = 1474 N·s/m （压缩）
```

**换算到减振器处**（÷i²，与刚度同律）：

```
c_dy = 2949 / 0.93² = 3410 N·s/m ≈ 3.41 N·s/mm （复原）
c_ds = 1474 / 0.93² = 1704 N·s/m ≈ 1.70 N·s/mm （压缩）
```

---

## 4.3 卸荷力

取减振器示功试验最大活塞速度 **v_max = 0.52 m/s**：

```
复原卸荷力 F_y = c_dy·v_max = 3410 × 0.52 = 1773 N ≈ 1.77 kN
压缩卸荷力 F_s = c_ds·v_max = 1704 × 0.52 =  886 N ≈ 0.89 kN
```

---

## 4.4 主要尺寸确定

### 工作缸直径

取缸内最大允许压力 **P_max = 2.5 MPa**，由复原卸荷力反推：

```
A = F_y / P_max = 1773 / 2.5×10⁶ = 7.09×10⁻⁴ m²
D_c = √(4A/π) = 30.0 mm
```

**取标准值 D_c = φ30**（减振器工作缸标准系列 20/30/40/45/50/65）。

### 活塞杆直径

按经验 d_g = (0.4～0.5)·D_c，取上限以兼顾侧向刚度：

**d_g = φ15**

### 贮油缸（外筒）尺寸

双筒结构，工作缸（φ30，壁厚 2 → 外径 φ34）装入贮油缸，环形储油腔宽约 4 mm：

```
贮油缸内径 = 30 + 2×2 + 2×4 = φ42
壁厚 2 mm → 外径 = φ46
```

**贮油缸（外筒）外径 = φ46** ✓（与市售同类产品 φ45～51 同量级，细节差异源于压力假设与圆整）

### 行程

轮心处：压缩行程 70 mm、复原行程 90 mm（第 1 节动挠度 + 复原行程设计值）：

```
活塞行程 S = (70 + 90) / 0.93 = 172 → 圆整取 S = 175 mm
```

---

## 4.5 阻尼参数反查（自洽校核）

由设计值反推相对阻尼比：

```
ψ_y = c_dy·i² / (2√(C·m_s)) = 3410 × 0.8649 / 7372 = 0.400 ✓
ψ_s = 1704 × 0.8649 / 7372 = 0.200 ✓
```

与 4.2 节设计目标完全一致（自洽）。

## 4.6 本节结论

| 项目 | 数值 |
|---|---|
| 形式 | 双筒式、油压+充气（气压 0.3~0.6 MPa） |
| 工作缸 | φ30 × 壁厚 2 |
| 活塞杆 | φ15 |
| 贮油缸（外筒） | **φ46 × 壁厚 2** |
| 行程 | 175 mm |
| 复原 / 压缩阻尼系数 | 3.41 / 1.70 N·s/mm |
| 复原 / 压缩卸荷力 | 1770 / 890 N |
| 相对阻尼比 | 0.40 / 0.20（平均 0.30） |

**衔接**：外筒 φ46 与行程 175 → 第 7 节减振器壳（筒身）长度与内部结构；活塞杆 φ15 上端 M14×1.5 螺纹接顶胶（第 5 节几何）。
