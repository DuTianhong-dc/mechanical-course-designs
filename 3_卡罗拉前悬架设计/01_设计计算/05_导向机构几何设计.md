## 5.1 坐标系与布置基准

**横断面坐标系**（车辆前视）：

- Z 轴：高度，向上为正

## 5.2 关键硬点坐标（★  反向修正）

**反解思路**：以**摆臂横向跨度 320**（= `20_下摆臂.toml` 的「有效摆长」）与
**侧倾中心 35 mm**（= `00_全局.toml` 的「侧倾中心高度目标」）为约束，
在保持主销倾角与官方一致的前提下反推出各硬点。

| 硬点 | 符号 | X (mm) | Y (mm) | Z (mm) | 说明 |
|---|---|---|---|---|---|
| 下摆臂内铰点（摆动轴线中心） | A | **+24.9** | **369.3** | **204** | 副车架上 |
| 下摆臂外端（下球头中心） | B | **+24.9** | **689.3** | 207 | 轮辋内侧、轮心下方（主销轴线上） |
| 支柱下端（转向节夹持中心） | S | **+24.2** | **686.4** | 220 | 与球头邻近（主销轴线上） |
| 支柱上支点（顶胶中心） | P | **−16.3** | **523.5** | 950 | 车身上（主销轴线上） |
| 轮心 | W | **0** | 763.5 | 317 | 基准点 |
| 轮胎接地点 | G | **0** | 763.5 | 0 | 轮心正下方 |

**各点的定法**：

```
先定三组约束：
  ① 主销内倾 12.58°、偏移距 28    → 主销轴线在 YZ 内的位置
  ② 主销后倾 3.17°                → 主销轴线在 XZ 内的倾角
  ③ 摆臂横向跨度 320、侧倾中心 35  → A 点的 Y 与 Z

再定 X 轴基准：
  取【轮心 X = 0】，并令【主销轴线在 XZ 投影内距轮心 18.8 mm（垂直距）】——
  即轴线在轮心【前方】18.8，保证拖距为正。
  （18.8 = 70_转向节.toml「主销偏移距离轴承中心」的模型值）
      轴线方程：X(Z) = +18.8 − 0.055383 × (Z − 317)
      即  Z=950 → X=−16.3（P） ｜ Z=220 → X=+24.2（S）
         Z=207 → X=+24.9（B） ｜ Z=0   → X=+36.4（轴线地面点）
```

**主销后倾拖距**：

```
拖距 = 轴线地面点 X(+36.4) − 接地点 X(0) = +36.4 mm
→ 正当值，落在乘用车常规 15~40 mm 内 ✓ 提供自动回正力矩
```

### 至主销轴线的距离（两个基点对比）

**基点二：轴承座中间面** —— 定义 = 转向节上轮毂轴承孔的**轴向中点**所在横截面，
其中心点（该截面与轴承孔轴线的交点）记作 **B_s**。

**轴承座中间面到轮心的距离：D = 22 mm（轴承座在轮心【内侧】）**

```
链条（轴向，自轮心向车内侧量）：
  ① 轮心 → 轮辋安装面 = ET = 40 mm          【硬数据】
     出处：E210 配 195/65R15 的原厂轮辋为 6.5J×15 ET40
  ② 轮辋安装面 → 转向节轴承孔外端面 = 30 mm  【估】
     依据：SKF VKBA 7811 轴承单元总长约 69~74 mm，其中约 40 mm 伸入转向节孔内
  ③ 孔外端面 → 孔中间面 = 64 / 2 = 32 mm     【实测】轴承座孔深 64
  → D = 30 + 32 − 40 = 22 mm
```

| 基点 | 坐标 | 至主销轴线 | 面内 | 面外 | 投影点在面内的位置<br>（相对 S：水平 / 竖直） |
|---|---|---|---|---|---|
| 轮心 W | (0, **763.5**, 317) | **98.4** | 89.1 | 41.7 | 69.1 ／ 97.0 |
| **轴承座中间面 B_s** | (0, **741.5**, 317) | **77.4** | 68.2 | 36.4 | **47.7** ／ 97.0 |

（"面内 / 面外" = 相对【含主销轴线且铅垂】的竖直平面分解；校验 77.4² = 68.2² + 36.4² ✓）
（面内水平方向为**朝车外偏前**——即 X 向前、Y 向外各占 0.24 / 0.97）

```
三维直线距离 77.4 mm（以轴承座中间面为基点）
  ├ 在【主销轴线 + 铅垂线】构成的竖直平面内 = 68.2 mm
  └ 垂直于该平面（面外）                    = 36.4 mm
```

> ⚠️ **仅剩 ② 是估算量**（其余三个输入：ET40 与孔深 64 均已确证）。
> ② 每 ±5 mm → D 每 ±5 mm → 至轴线距离约 ∓4.8 mm：
> `②=20 → 86.9 ｜ 25 → 82.1 ｜ 30 → 77.4 ｜ 35 → 72.6 ｜ 40 → 67.9`

> 该竖直平面：含主销轴线且铅垂，法向 n̂ = (−0.9706, +0.2409, 0)。
> 在平面内，轴线过 S 点、与竖直线成 **12.95°**；两个基点的【投影点】相对 S 的坐标见上表末列。

### 摆臂球头中心 B ↔ 支柱下支点 S 的距离（★ 新增）

```
B (24.6, 689.3, 207)  ↔  S (23.9, 686.4, 220)

距离 = 13.3 mm        （两者同在主销轴线上 → 即为沿轴间隔）
   分量：ΔX +0.7 ｜ ΔY +2.9 ｜ ΔZ −13.0
```

> 共线复核：S→B 与 S→P 的方向余弦 = **−1.0000**（严格共线）✓
> 故该距离**不依赖任何未知量**，完全确定。

> ⚠️ **建模留意**：两者仅差 13.3，而**夹口插入深为 70**。
> 若 S 取夹口**中心**，夹口跨 Z 185～255，会把球头中心（207）**包在里面**
> —— 球头座与夹口凸耳将重叠。
> 实际布置应为：球头座在下、夹口凸耳向上伸，夹口下缘须高于球头座上缘
> （约 B+25 ≈ 232）→ **S 宜上移至 Z ≈ 270**。
> S 沿轴线上下移动**不改变任何定位参数**（轴线由 P、B 定义），
> 但须与减振器下支架的实际轴向位置对齐 —— 即待办第 1 条（下支架轴向位置）。

**下摆臂长度（水平投影）**：

```
L_A = 689.3 − 369.3 = 320 mm
```

**下摆臂布置**：内端（204）略低于外端（207），微上翘约 **0.56°**。
摆动轴线取**纯横向**（A 与 B 同 X = +24.9）—— 简化假定，避免引入额外的后倾变化。

### 主销轴线方向的三种表述（★ 概念区分）

主销轴线是一条**空间斜线**，它与铅垂线的夹角要按**投影平面**区分，三者不可混用：

| 表述 | 所在平面 | 数值 | 用途 |
|---|---|---|---|
| **主销内倾角** SAI | **YZ 横断面**（前视） | **12.58°** | 四轮定位参数 |
| **主销后倾角** Caster | **XZ 纵断面**（侧视） | **3.17°** | 四轮定位参数 |
| **与铅垂线的真夹角** | 三维（轴线+铅垂构成的面） | **12.95°** | 转向节/顶胶的**实际装配角** |

```
cos(12.95°) = 1 / √(1 + tan²12.58° + tan²3.17°)
真夹角恒大于任一投影角 —— 因为两个倾角叠加了。
```

> ⚠️ **注意区分**：「含主销轴线且垂直于 XZ 平面」的那个平面**并不含铅垂线**
> （铅垂线与它成 3.17°），在其中正视作图量到的是 **12.56°**（≈SAI）。
> 若要直接画出/量出真夹角 12.95°，须用**【主销轴线 + Z 轴】两线**建平面
> （该面为竖直面，方位角自 XZ 面转 76.1°）。

## 5.3 主销轴线与倾角校核

主销轴线 = 支柱上支点 P 与支柱下端 S 的连线：

```
横向倾角（主销内倾）：
α = atan[(686.4 − 523.5) / (950 − 220)] = atan(162.9/730) = 12.58°

纵向倾角（主销后倾）：3.17°
   支柱上下端纵向偏置 = (950 − 220) × tan 3.17° = 730 × 0.05542 = 40.4 mm
```

| 定位参数 | 设计值 | 常规范围 | 结论 |
|---|---|---|---|
| 主销内倾角 | **12.58°** | 12°～15° | ✓ |
| 主销后倾角 | **3.17°** | 2°～6° | ✓ |
| **主销偏移距**（横向） | **+28 mm** | 0～30（前驱） | ✓ 接地点在轴线外侧 |
| **主销后倾拖距**（纵向） | **+17.6 mm** | 15～40 | ✓ 正当值，自动回正 |
| 车轮外倾角（静态） | **−0.58°** | −0.5°±0.5° | ✓（装配设定） |
| 前束（静态） | **0°** | 0～0.2° | ✓（装配设定） |

## 5.4 侧倾中心高度（作图法解析计算）

**瞬心 IC 求法**（麦弗逊作图规则）：

1. 下摆臂线 AB 的延长线（A(369.3,204) → B(689.3,207)，斜率 = 3/320 = **0.009375**）：
   `z = 204 + 0.009375·(y − 369.3)`
2. 过 P 作支柱轴线的垂线（支柱轴 PS 斜率 = (220−950)/(686.4−523.5) = **−4.481**，垂线斜率 = **+0.2232**）：
   `z = 950 + 0.2232·(y − 523.5)`
3. 两线交点（瞬心）：**IC = (−2959, 173)**
4. 接地点 G(763.5, 0) 与 IC 连线（斜率 = 173/(−2959−763.5) = **−0.046414**），交车辆中心线 y = 0：

```
h_rc = 0.046414 × 763.5 ≈ 35.4 mm
```

**侧倾中心高度 h_rc ≈ 35 mm**（常规范围 0～100 mm ✓），与全局表目标一致。

> ⚠️ **符号提示**：侧倾中心必须在**地面之上**取正。反解时若 A 的高度取低了
> （例如 180.3），算出的 z 会变成负值（落在地面以下），那是不成立的解。
> 本次取 A 的 Z = 204，得 h_rc = +35.0 ✓

## 5.5 运动校核

**摆臂摆角**（轮心总行程 = 压缩 70 + 复原 90 = 160 mm）：

```
θ_total = asin(160/320) ≈ 30.0°   （压缩 12.8° / 复原 16.4°）
```

**轮距变化估算**（摆臂圆弧效应，单侧）：

```
压缩极限：L(1−cos 12.8°) ≈ 8.0 mm
复原极限：L(1−cos 16.4°) ≈ 13.0 mm
```

全行程轮距变化 ≈ 15～20 mm。摆臂由 450 缩到 320 后，同样的行程对应的摆角变大，
轮距变化比早先按 450 估的（10~15 mm）略大，仍在紧凑型轿车可接受范围；
精确值以 CAD 运动校核为准。
