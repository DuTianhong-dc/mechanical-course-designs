# 03 · 螺旋弹簧设计

> 卡罗拉（E210）前悬架设计 · 设计计算书 第 3 节

---

## 3.1 设计输入（第 1、2 节）

| 参数 | 数值 |
|---|---|
| 弹簧刚度目标 k | 33.4 N/mm |
| 满载静载 F_s | 4.96 kN |
| 弹簧静压缩量 δ_s | 148.8 mm |
| 轮心动挠度 f_d | 70 mm（其中弹性段 50 mm，其余 20 mm 由缓冲块承担） |
| 杠杆比 i | 0.93 |

---

## 3.2 材料选择

**60Si2MnA**（GB/T 1222 弹簧钢，汽车悬架螺旋弹簧标准用材；淬火+中温回火 + 喷丸强化工艺）。

| 材料参数 | 取值 | 说明 |
|---|---|---|
| 抗拉强度 σ_b | ≥ 1650 MPa | 现代悬架弹簧工艺水平 |
| 许用工作切应力 [τ] | 0.46σ_b ≈ **760 MPa** | 循环载荷工作工况 |
| 许用极限切应力 [τ]_max | 0.65σ_b ≈ **1070 MPa** | 极限压缩/冲击工况 |

剪切模量 G = 79 000 MPa。

---

## 3.3 结构参数确定（试算）

**旋绕比**取 c = D/d ≈ 8.7（汽车悬架弹簧常见 8～10，取较低值以控制径向尺寸）。

**曲度系数**（考虑弹簧丝曲率对内侧应力的放大）：

```
K = (4c + 2) / (4c − 3)
```

**应力公式**（弹簧丝最大剪切应力）：

```
τ = 8·F·D·K / (π·d³)
```

**试算**：令静载工况 τ_s ≤ [τ] = 760 MPa，F_s = 4963 N，取 D = 9d 初试：

```
τ_s = 8 × 4963 × 9d × K / (π·d³) ≈ 131 000 / d²  ≤ 760
→ d ≥ 13.1 mm
```

**圆整取 d = 13.5 mm**，相应调中径使刚度吻合（下节验证）：

**最终参数**：

| 参数 | 符号 | 数值 |
|---|---|---|
| 线径 | d | **13.5 mm** |
| 中径 | D | **118 mm** |
| 旋绕比 | c = D/d | 8.74 |
| 曲度系数 | K | 1.157 |

---

## 3.4 有效圈数与刚度校验

**刚度公式**：

```
k = G·d⁴ / (8·D³·n)
```

由 k = 33.4 N/mm 反解：

```
n = G·d⁴ / (8·D³·k) = 79 000 × 13.5⁴ / (8 × 118³ × 33.4) = 6.03
```

**取有效圈数 n = 6**（圆整），实际刚度：

```
k' = 79 000 × 13.5⁴ / (8 × 118³ × 6) = 33.3 N/mm
```

与目标 33.4 N/mm 偏差 0.3 % ✓（对应实际偏频 ≈ 1.25 Hz，无需迭代）

---

## 3.5 应力校核

**曲度系数复核**：K = (4×8.74+2)/(4×8.74−3) = 1.157

**静载工况**（F_s = 4963 N）：

```
τ_s = 8 × 4963 × 118 × 1.157 / (π × 13.5³) = 701 MPa ≤ [τ] = 760 MPa ✓
```

**极限工况**（弹簧最大工作变形，弹性段动挠度 50 mm 折算）：

```
δ_max = δ_s + i·f_de = 148.8 + 0.93×50 = 195.3 mm
F_max = k'·δ_max = 33.3 × 195.3 = 6504 N
τ_max = 701 × 6504/4963 = 919 MPa ≤ [τ]_max = 1070 MPa ✓
```

---

## 3.6 几何尺寸汇总

| 参数 | 数值 | 说明 |
|---|---|---|
| 总圈数 n₁ | **8**（= 6 + 2 支承圈） | 两端并紧磨平 |
| 自由长度 H₀ | **330 mm** | 按装配空间设定 |
| 满载装配长度 H_s | 330 − 148.8 = **181.2 mm** | |
| 节距 p | (H₀ − 1.5d)/n = **51.6 mm** | |
| 压并高度 H_c | (n₁ − 0.5)·d = **101.3 mm** | |
| 最大工作长度 | 330 − 195.3 = 134.7 mm（> H_c，余隙 33.4 mm ✓） | |
| 高径比 b = H₀/D | 2.80 < 5.3 | 稳定性无需额外校核 ✓ |
| 展开长度 | π·D·n₁ ≈ **2966 mm** | |

---

## 3.7 本节结论

| 项目 | 数值 |
|---|---|
| 材料 | 60Si2MnA（σ_b ≥ 1650 MPa） |
| 线径 × 中径 | **φ13.5 × φ118** |
| 有效圈数 / 总圈数 | 6 / 8 |
| 自由长度 | 330 mm |
| 实际刚度 | 33.3 N/mm |
| 应力校核 | 静载 701 / 极限 919 MPa（均通过） |

**衔接**：弹簧满载装配长度 181.2 mm 与上座位置 → 确定减振器弹簧盘位置（第 7 节）；弹簧盘直径按弹簧中径 118 + 线径设计（第 7 节）。
