## 3. 实测配方与坑（2026-10-11 沉淀）

### 3.1 SW 连接
- `win32com.client.GetActiveObject("SldWorks.Application")` + **打印 PID 核对**（连用户现用实例）
- **makepy 静态绑定**（`GetModuleForTypelib("{83A33D31-27C5-11CE-BFD4-00400513BB57}", 0, 34, 0)`）
- **所有接口返回值都要 `staticize`**（动态派发下 `.Extension` 等属性会报"找不到成员"）
- 打开文档：**`OpenDoc6` 报"类型不匹配(-2147352571)" → fallback `OpenDoc(path, type)`**（2=装配 / 1=零件，Silent 模式）

### 3.2 改参（txt 字节级替换）
- 键名**含 ASCII 双引号**（`"主体管壁厚" = 3`）
- **bytes 字面量不能含中文** → `KEY = '"参数名"'.encode("utf-8")` 拼正则
- 改前**必备份**（`.bak_flow_时间戳`）；UTF-8-sig + CRLF 原样保留

### 3.3 读入与重建
- `em.UpdateValuesFromExternalEquationFile()` → `doc.EditRebuild3()`
- **EditRebuild3 返回 False = 重建失败**（第一道检测）

### 3.4 ★ 错误检测（本流程的核心能力）
- **两层遍历**：`doc.FirstFeature()` → `GetNextFeature()` → `IFeature.GetErrorCode()`（非零即报）
- 零件级 + 装配级**都要查**（装配会捕获组件级联：实测 `[转向节-1] Reference 错误码=1`）
- **实测错误谱系**（转向节 25 案例）：草图（码 1）→ 凸台/切除（码 1/37）→ 圆角（码 12）——**级联链完整可见**
- ⚠️ **重要洞察**：**"坏几何"仍能通过 SaveAs 导出**（返回 True）→ **自动化绝不能"只要导出成功就认为成功"——检测必须在导出之前做**
- 错误码语义待补（1/12/37 对应字典待查 SW API）

### 3.5 回滚与验证
- **回滚 = 从备份还原 txt**（比反向替换更稳）；关闭文档**丢弃**几何改动
- **复验 = 重开零件读体积 == 基线**（两次实验均 PASS——"模型库零污染"硬验收）


## 6. 错误处理策略（实测确立）

```
改参 → 重建 → 【查错】─┬─ 无错 → 读新值 → 发布 x_t → 回滚 → 复验 → runlog(OK)
                      └─ 有错 → 打印错误清单（特征/类型/码）
                                → 不向 inbox 发布
                                → 探测导出到 logs\（行为证据留痕）
                                → 回滚 → 复验 → runlog(REBUILD_ERROR)
```

- **发布门槛**：只有"重建无错"的几何才有资格进 inbox——这是后续 ANSYS 导入的入口把关
- **留痕**：报错现场（名单+探测文件+日志）完整保留，供"改参合理性"研判

## 7. ★ 几何替换路线 —— 实测配方（2026-10-13 全链打通）

> 路线核心：**从"已验收的底模型"出发，原位换几何 + 全 API 接线修复 + 原工况导出**。
> 相比"从零复刻链"（`ANSYS\automation\rebuild\`）：**免 dfs 手术、免重建工况对象、网格配方继承**（44k 节点 vs 复刻链 114k → 求解快 2.5×）。
> 底模型：`ANSYS\suspension_geoswap_repaired.mechdb`（= meshtest 修复版 + φ27 几何 + 全修复，10-13 定稿；两个 presolve 备份同目录）

### 7.1 全链步骤（每步=脚本，全部 API 化）

| 序 | 步骤 | 操作 | 验证点 |
|---|---|---|---|
| G0 | 底模型副本 | 复制 mechdb → 新名，会话打开（`_launch_gui_session.py` 10504） | 全树 FD（`_final_check.py`） |
| G1 | 换几何 | `gi = Model.GeometryImportGroup.Children[0]; gi.Import(新x_t)`（~15s 原位替换）→ **删全部"接头*"**（reload 自动生成 ~396 个 → 按名批量 `Delete()`） | 51 part / 91 body 保持；接头清零 |
| G2 | **完备性扫描** | 全树扫 UnderDefined 清单（连接/弹簧/NS/远程点/点质量/坐标系/网格设置） | `_final_check{,_server}.py` 各节点状态 |
| G3 | 接线修复（4 类） | ①关节 `Mobile/RefLocation`=新**面**id；②网格设置 5 对象 `Location`=新**体** id；③弹簧 `Reference/MobileScopeLocation`=新**面** id；④NS `Location`、远程点/点质量 `Location`、CS `OriginLocation`=新面/体 id | 全 FD（对照 gold 10505 金标准） |
| G4 | 网格 | `Model.Mesh.GenerateMesh()`（~11s） | Solved / 44,412 节点 / 设置全 FD |
| G5 | 导出 | `a.Solve()`（见 7.3-②） | `file.dfs` 25MB + dfg/dfm/dfr/ssc/dfsxml（~54s） |
| G6 | 注入 | `inject_case.py <src.dfs> <out.dfs> --workdir DIR --ssc "5 250 0"` | report 修正 6 项；与 MESHTEST_INJ 同构 |
| G7 | 跑批 | workdir 内 `rundfs.exe -i file -o resX -t 16`（PATH：Console+IntelMKL+CPython+System32） | res.out 正常；err 仅设计性冗余警告（6 条=黄金同级） |
| G8 | 判读 | `_goswap_read.py <disp> 5.0 250` | 482kg 有界 + 驱动跟随 + rel 稳定 |

### 7.2 ★★★ 关键知识：换几何后"id 重排"的四种 id 空间（必背）

| id 空间 | 用途（对象） | 获取/写入方式 |
|---|---|---|
| **面 id** | 关节 Location、弹簧 Scope、NS、远程点/点质量、CS Origin | `sel = ExtAPI.SelectionManager.CreateSelectionInfo(SelectionTypeEnum.GeometryEntities); sel.Ids=[面号]` |
| **体 geo id** | 网格设置 Location、CS Origin（体级） | `int(body.GetGeoBody().Id)` |
| **ObjectId** | 坐标系等对象级对齐（**reload 后保留**，可与 gold 直接对号） | `obj.ObjectId` |
| **名字（hex 通道）** | 所有按名重绑场景（防中文/一字之差） | `name.encode("utf-8").encode("hex")` |

- **面号重配法**：dump 两侧全量面指纹（`_dump_faces_live*.py`：面号/面积/质心/类型/所属体）→ 按"类型+面积+质心"匹配（**同心球面必须加 gid 所属体约束防交叉错配**）
- **金标准对照法**：**10505 会话常开 gold（meshtest）**——任何修复前先读 gold 同对象的金标准值（Location.Ids / 属性 / 状态），再映射到新几何（本例映射记录：2523→5396 / 2463→5343 / 2655→2659 / 2684→5472 / 2295→5222 …）

### 7.3 坑清单（血泪浓缩）

1. **reload 四坑**：①自动生成 ~396「接头」（按名清）②**面号约半数失效**（重配）③**70 件柔性化/材料/体名被冲掉**（重设）④**网格设置 scoping 全清空**（重设）
2. **`a.GenerateInputOnly` 不是方法、是 bool 开关**（值=True）——历史所有 `TypeError('bool is not callable')` 就是把它当函数调了；**真正触发导出 = `a.Solve()`**
3. **Solve 前必须全 FD**——否则 **771 秒静默流产后零产出**；全 FD 后 **54 秒成功**（"导出墙"真相）
4. **只读属性集**：`Joint.Type/ConnectionType`（既有对象上）、`spring.ReferenceBody/MobileBody`；但 `MobileLocation`/`ScopeLocation`（填面 id）可写
5. **名字一字之差**（"衬套**铰**接"≠铆接）；别手敲中文——从数据文件取名转 hex
6. **探测会话强杀会锁副本**（`.mech_lock`）→ 探测一律用全新副本
7. **端口分区**：10504=工作会话（GUI 可见）｜10505=gold 对照（只读）

### 7.4 判读配方（`_goswap_read.py`）

- **组号（位置交叉锚定，dc≤0.0001mm）**：**482kg 质量块=g61**（对应 v3 的 g66）｜**内层=g50**（v3 g56）｜**法兰=g8**（v3 g6）｜**转向节=g11**（v3 g5）
- **disp 格式**：帧长 1,074,353B = [100B 头] + 帧×[8B 时间 + 44,764 点×24 + 9B"TSTEP"]；实体 96B = pos(3)+rot(9)（直存，位置直接可读）
- **健康判据**：482kg **振荡有界**（爬升→峰值→回落→回摆；0.36s 峰 +72.6 / 0.80s -24.7，p-p≈97 ≈ meshtest 93）；驱动 40sin 精确跟随；rel 稳定 15-27mm
- **病态特征**（对照 C1L）：单调加速下坠、不回头（0.13s 就 27mm 且加速）
