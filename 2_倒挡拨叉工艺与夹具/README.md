# 2 · 倒挡拨叉工艺与夹具设计

> 机械制造工艺课程设计 —— **倒挡拨叉机械加工工艺规程及工艺装备（夹具）设计**

本目录是课程设计的完整数字化存档：三维模型（SolidWorks）、图纸（AutoCAD）、设计说明书。

---

## 📁 项目内容

### `模型/` —— SolidWorks 三维模型

| 内容 | 说明 |
|---|---|
| `夹具装配.SLDASM` | **完整夹具总装体**（20 个组件），从这里开始看 |
| `V型块 / 基座 / 心轴 / 手柄 / 挡块 / 轴 / 顶针` | 夹具功能零件 |
| `倒挡拨叉毛坯.SLDPRT` | 装配中实际夹持的工件（毛坯件）|
| `倒挡拨叉.SLDPRT` / `夹具基座.SLDPRT` | 成品零件（未参与夹具装配，作为资料保留）|
| `标准件/` | SolidWorks Toolbox 实体化的标准件：六角头螺栓、平垫圈 —— **已实体化，无需配置 Toolbox 即可打开** |

> **`兼容版_SW2024/` —— 旧版本兼容包**（13 个文件）
> 原版模型为 SolidWorks 2026 格式（2024 及更早版本打不开）。本目录提供**降版到 SolidWorks 2024** 的完整一套：
> - 使用 **SolidWorks 2024 / 2025 / 2026** 均可直接打开 `夹具装配.SLDASM`
> - 特征树完整保留；与上级 `模型/` 为同一模型的两个格式版本，取用时按文件夹区分

### `图纸/` —— AutoCAD 图纸

| 文件 | 说明 |
|---|---|
| `倒档拨叉.pdf` | 倒挡拨叉零件图 |
| `基座.dws` | 夹具基座图（AutoCAD 2018+ 图形格式）|
| `夹具总装图.dws` | 夹具总装图 |

### `文档/` —— 设计说明书

| 文件 | 说明 |
|---|---|
| `课程设计说明书.docx` | 工艺规程与夹具设计说明书 |

## 🚀 打开方式

1. **SolidWorks 2026**（或更高版本）打开 `模型/夹具装配.SLDASM`；使用旧版软件请前往 `模型/兼容版_SW2024/`（2024 及以上可直接打开）；
2. 全部零件与标准件都在同一目录内，模型**自包含**——直接打开即可，无需做任何引用定位；
3. 图纸用 **AutoCAD 2018 及以上**打开。
